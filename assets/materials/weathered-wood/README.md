# Weathered timber photography

Source: [Weathered Planks, Poly Haven](https://polyhaven.com/a/weathered_planks).
Photography: Dimitrios Savva. Processing: Dario Barresi.
License: [CC0](https://polyhaven.com/license).

Local 1024×1024 JPEG color, OpenGL normal and roughness maps downloaded
2026-09-22 from Poly Haven's 1K weathered_planks material. About 1.43 MiB total.
Temple loads these once, crops the post material from one board, and lightly
stains the gate variant. It keeps procedural wood as a loading fallback.
No remote requests are needed at runtime.
